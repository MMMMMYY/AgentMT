已为既定 116 条 source 生成七种语言翻译，共 812 条；英语原文逐字保留，共 928 条文本。任务名单未变，未使用 tone 变体作为翻译输入，未执行任何 agent 任务。

语言来自此前 WildChat 频率选择：英语、中文、俄语、法语、西班牙语、阿拉伯语、德语、葡萄牙语。中文采用简体，阿拉伯语采用现代标准书面语；葡萄牙语未作独立地区变体比较。

## 阅读和使用

- `PROMPTS.md`：按任务排列的八种语言文本，附检查状态。
- `all_prompts_audited_v2.jsonl`：当前推荐的程序输入候选集合，含 source、语言、翻译、模型检查与 v2 字面检查。
- `review_queue_v2.json`：40 条待复核翻译，不直接用于正式 MT 实验。
- `audit_summary_v2.json`：772 条通过自动检查，40 条待复核；每种语言各 116 条。
- `all_prompts.jsonl` / `summary.json`：生成阶段的 v1 检查，保留作审计，不以此代替 v2。
- 每个任务目录中的 `source.json`、`translator_request.json`、`translator_raw.json`、`reviewer_request.json`、`reviewer_raw.json` 和 `suite.json` 保留来源、完整请求与原始模型返回。
- `attempt1_incomplete/`：重试前的失败/不完整记录；`retry1_manifest.json` 明确记录重试范围。

## 方法和边界

使用 Gemini 2.5 Flash，温度 0，直接 source-to-target 翻译；审核在同模型的另一个独立上下文中进行。这不是人工或独立模型验证，也不证明跨语言语气完全一致。

要求保留任务、授权、原语气、信息顺序、条件、对象和身份，不修正原任务。专有应用名称及操作相关字面量、引号内指定文本保留原样。因此某些翻译含英文 payload，是有意控制操作对象，而非全文每个字都翻译。

自动审核分别检查任务等价、授权等价、语气、信息顺序和目标语言。v2 字面检查修正中文/其他非拉丁文字紧邻数字时的漏认。检查偏保守，日期格式、千分位、序数或数字改用文字等可能语义等价但仍进入复核队列；40 条不等于 40 条确定的语义错误。

其中一个日历任务的模型审核两次均未返回全部语言，七条暂时统一待复核；原始返回保留。已看到中文 busy/free 反转等值得修正的候选，不自动删除，也不凭模型整体通过率宣称全部可用。

所有 source 与既定 manifest 一致。116×7 的生成已完成，但正式实验前仍应复核候选质量，特别是跨语言语气和授权语义。90 项本地测试通过；测试通过不代表翻译语义得到证明。
