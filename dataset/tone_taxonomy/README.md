# Hierarchical tone and surface-form inventory v2

This version separates inventory construction from later experimental sampling:

`tone -> subcategory -> multiple observed surface forms`.

The classified inventory currently contains 23 English forms: 16 polite, five
neutral, and two impolite. A further 27 observed forms remain in the pending
inventory because Stanford provides insufficient direct evidence or because the
form does not determine tone without dialogue context.

Direct Stanford evidence is preferred. Some longer forms inherit the tone of a
directly supported parent construction, such as `can you` -> `can you help me`;
these rows are explicitly marked and require validation. WildChat counts are
surface-prefix or suffix support values and may overlap. They describe the
prevalence of forms, not mutually exclusive prompt classes.

No representative is removed from this inventory. Selecting one form per
subcategory, if needed for a small experiment, is a separate downstream step.
